# msgboard

## progress.txt is the todo list

`progress.txt` at the repo root is the project's todo list and status record.

- Read it at the start of every session. Keep it short: condense finished work to one line per period.
- Update it before you end any session that shipped, deployed, found or deferred something.
  Put new entries at the top, dated.
- Track open work there. Do not open GitHub or GitLab issues unless the owner asks for one.
- Claude's private memory notes are not a substitute. Anything the next session must act on goes
  in `progress.txt`.
