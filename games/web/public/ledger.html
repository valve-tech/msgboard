Group B · P2P coin flips

A "guessing duel" — matching pennies. There is no house, no validator, and no randomness at all. Each side's own guess protects its expected value; a commit-reveal bond closes the free option.

Group C · House casino games

Testnet 943 only

The large catalog: one player against the house, on an EIP-712 co-signed session. The RNG commit lands before the bet; disputes replay the transcript on-chain. Twenty games carry a pure on-chain recompute mirror; eight ride the co-signed path only. The house pool (HouseChannel) is deployed on 943 only — none of these run on mainnet yet.

Group D · ZK masked-deck card tables

Testnet 943 only

State-channel card games with private cards. A ZK shuffle and per-seat decryption shares hide the deck; the channel state is co-signed and an on-chain dispute machine enforces every legal transition. Escrow is denominated in the x402Pls wrapper. Deployed on 943 only.

GameLayerPlayer modelFairnessCustodyTrustAddress
Hi-Lo War⚔️ Hi-Lo War both 2-party fixed channel ZK shuffle + commit-reveal; on-chain dispute machine Two fixed channel escrows cosigned
Hold'emTexas Hold'em · poker on-chain N-party, 3–9 seats ZK masked deck (secp256k1 ElGamal), per-seat shares N-seat channel escrow, side-pots + rake at settle cosigned

Hold'em is not yet a playable web tab. The contracts and TS engine exist and are wired in config, but there is no entry in the web GAMES array. Also, multiway showdown winner-selection and rake are not fully implemented — only an uncontested (single live seat) showdown resolves today.

Group E · ZK skill games

Group F · Operator substrate

Testnet 943 only

The table-maintainer system: permissionless, bonded operators run their own house, and cannot rug players because the rules live in code. This is the only game that supports the tradeable bonus economy. Deployed on 943 only — mainnet has no operator substrate yet.

GameLayerPlayer modelFairnessCustodyCurrencyBoostTrust
OperatorCoinFlipcoin flip · 943 0x0c80…1833 on-chain Player vs bonded operator house Validator entropy + IRandomStaking Shared GameEscrow, per-(operator, token) isolated ledgers any ERC-20 ◆ boost validator

The boost is an ERC-1155 charge (BonusChips1155) that narrows the house-vs-player win rate. It is collateralized by BackingPool, sold through MintSale, and resold non-custodially on Marketplace. Fee and validator policy are pluggable; operator rake is capped at 5%.
